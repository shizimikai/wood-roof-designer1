# 木の屋根 設計ツール（2x4材）

ホームセンターで買える **2x4系の木材（2x4・2x6・2x8・2x10）** と **4x4材の柱** で、庭の屋根・パーゴラ・簡易車庫・小屋などを作るときの、ブラウザで動く簡単な設計ツールです。
[tankan-designer](https://github.com/shizimikai/tankan-designer)（単管パイプ版）の木材版です。

寸法を入れると次のものが出ます。

- 3Dで回して見られる骨組み（柱・桁・垂木・母屋・棟木・陸梁・束・方杖・筋交い・胴つなぎ・壁の枠）。木材は実際の断面の大きさで表示します
- 部材リスト（部材ごとの長さと本数）
- **木取り表**：どの定尺（6〜16フィート）から、どの部材を切り出すか。短い部材はまとめて1本から切るので、買う本数が少なくなります
- 購入リスト（木材の本数、ボルト、ハリケーンタイ、ビス、柱脚金物、波板、合板、塗料など）
- 概算の材料費（単価は画面で変えられます）
- 勾配・部材の太さの目安・補強・建築確認などの注意

## 使い方

`index.html` をブラウザで開くだけです（three.js は CDN から読み込みます）。
GitHub Pages を有効にすれば、そのURLでスマホからも使えます。

- 屋根の形：片流れ／切妻
- 柱は 4x4材。間口方向・奥行き方向の本数を設定
- 桁：2x6／2x8／2x10、2枚で柱を挟む（ボルト留め）か、外側に1枚か
- 垂木：2x4／2x6／2x8、間隔（この間隔以下になるように本数を決めます）。母屋（横桟）は2x4材
- **壁（面ごと）**：前・後・左・右それぞれに「なし／上まで／腰壁」を選べます
  - 壁の材料：構造用合板（下枠・上枠・間柱）／波板（胴縁）／杉板の縦張り（胴縁）
  - 切妻の妻側（左右）を「上まで」にすると、三角の部分もふさぎます
- **補強（面ごと）**：なし／方杖／筋交い／たすき。筋交いは下端・上端の高さを変えられます
- 胴つなぎ（面ごとに高さ）
- 基礎の種類：コンクリートの土間に固定／羽子板付き束石／穴を掘ってコンクリート（深さ・直径を設定）／打ち込み式ポストベース
- 防腐処理材にするか、塗装するか（塗料の量を木材の表面積から計算）
- 用語や入力欄の横の「？」にカーソルを合わせる（スマホはタップ）と、初めての人向けの説明が出ます
- **3面図**：平面図・正面図・右側面図を寸法（mm）付きで表示。SVGで保存、A4/A3横で印刷できます
- **設計の保存と比較**、**JSONの書き出し・読み込み**、**URLで共有**、**購入リストのCSV保存**（tankan-designer と同じ）

### JSONの形式

```json
{
  "app": "wood-roof-designer",
  "version": 1,
  "designs": [
    { "name": "物置の屋根", "savedAt": "2026-11-19T00:00:00.000Z", "params": { "W": 3, "D": 2.5, "roofType": "mono", "H1": 2.6, "H2": 2.3, "wB": "full", "wMat": "ply" } }
  ]
}
```

`params` に書いていない項目は初期値になります。

## 計算の前提

- 高さは基礎の上（柱の足元）から測ります。「前の高さ・軒の高さ」は桁の上の面、「棟の高さ」は真ん中での垂木の下の面です
- 定尺は 6F=1820 / 8F=2438 / 10F=3048 / 12F=3658 / 14F=4267 / 16F=4877mm。4x4材は12Fまで
- 部材1本ごとに切りしろ（初期値20mm）を足して、定尺に割り付けます。16Fより長い部材は分けて継ぐ計算です
- 部材の長さは中心線での目安です。垂木の欠き込みや斜めの切り方は現物に合わせてください
- 金物：桁と柱はM12ボルト2本、垂木と桁はハリケーンタイ1個、2x材どうしはコーススレッド90mm（本数は目安）
- 波板は働き幅58cm、長さは6〜12尺から選びます
- 単価は2026年時点のホームセンター価格（SPF無処理）をもとにした目安です

**強度計算はしていません。** 部材の太さの注意（垂木・桁が渡せる長さ）は、軽い波板の屋根・雪の少ない地域を考えた大まかな目安です。積雪や強風のある地域では太くし、不安な場合は専門家に相談してください。

## ファイル

- `index.html` — 画面と3D表示
- `wood-core.js` — 部材・金物・木取り・費用の計算ロジック
- `drawing.js` — 3面図（SVG）を描く
- `glossary.js` — 「？」で出す用語の説明
